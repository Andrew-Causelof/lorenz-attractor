# Аттрактор Лоренца

Интерактивная WebGL-визуализация системы Лоренца (1963): хаотический поток в трёхмерном фазовом пространстве.

$$\dot x = \sigma(y-x),\quad \dot y = x(\rho-z)-y,\quad \dot z = xy-\beta z$$

Классические параметры: σ = 10, ρ = 28, β = 8/3.

## Возможности

- Живая интеграция RK4, несколько траекторий с общим потоком
- Пресеты: классика, покой, порог, период, плотность
- Раскраска по высоте, скорости или возрасту следа
- Вращение камеры, пауза, перезапуск, малое возмущение
- Работает на телефоне и на десктопе

## Запуск

```bash
npm install
npm run dev
```

Сборка:

```bash
npm run build
```

Нужны Node.js 22+ и современный браузер с WebGL.
